# Can data predict award voting?
In this project, I investigated the statistical drivers behind historical NBA MVP voting patterns. This project allowed me to hone existing skills while developing new ones.

* Data Engineering: Automated multi-source extraction by using JavaScript to scrape dynamic DOM tables, feeding raw data into R, which I then further processed into ML inputs and interactive graphs.

* Statistics and Analytics: Developed custom metrics (e.g., standardizing "vote share" and creating an "Unexpected Wins" derivative) to mathematically proxy qualitative media and team-performance narratives.

* Predictive Modeling: Built and validated a machine learning regression pipeline, utilizing a 3rd-degree polynomial model to capture non-linear voter tendencies, achieving a 67% R-squared rating on test data.

* Presentation: Deployed a Quarto dashboard featuring responsive Plotly radar charts for multi-dimensional athletic profile comparisons.

My model predicted Nikola Jokic as the 2025-26 NBA MVP. However, Shai Alexander was the player who won the award that year. But even though the model might seem inaccurate, in all trials, Jokic was closely followed by Shai.
